# Customer Churn Prediction

## Overview

A machine learning project that predicts whether a telecom customer is likely to leave a service using customer demographics, service subscriptions, contract details, and billing information. It uses classification algorithms and a preprocessing pipeline.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn

## Features

- Analyzes customer information and service usage.
- Preprocesses numerical and categorical features.
- Handles missing values and encodes categorical data.
- Trains and compares Logistic Regression, Decision Tree, Random Forest, and XGBoost classifiers.
- Predicts whether a customer is likely to churn.
- Evaluates model performance using accuracy, precision, recall, and F1-score.

## How to Run

1. Install the required libraries:

   `pip install -r requirements.txt`

2. Place the `Telco-Customer-Churn.csv` dataset in the project folder.

3. Open and run the `cp.ipynb` Jupyter Notebook cells in order.

## Disclaimer

Predictions are estimates based on the available dataset and do not guarantee actual customer behavior.
